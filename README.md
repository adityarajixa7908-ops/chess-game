# ♟️ Chess Game

A C++ chess game built from scratch with complete chess rules, move validation, and AI.

## 📌 About the Project

This project is a chess game developed using C++. The goal is to implement the core rules and logic of chess from scratch and gradually develop it into a complete playable chess application.

The project will begin as a console-based game and will be improved with advanced features such as move validation, checkmate detection, and chess AI.

## 🚀 Features

- Chess board and pieces
- Player vs Player gameplay
- Legal move validation
- Piece capturing
- Check and checkmate detection
- Stalemate detection
- Castling
- En passant
- Pawn promotion
- Move history
- Chess AI
- Graphical User Interface

## 🛠️ Technologies

- C++
- Git
- GitHub
